# 記事リライト

## 手順

0. **ルールを読む**
   - `rules/` の共通ルールを読み、次に `sites/<ドメイン>/` のサイト別ルールを読む。食い違う場合はサイト別ルールを優先する。

1. **対象を決める**
   - `python3 tools/wp.py sites` でサイト一覧（ドメイン・サイト名）を確認する。ユーザーはサイト名やジャンルで呼ぶことがあるので、一覧と照らしてドメインを特定する。
   - 記事IDが分からなければ `python3 tools/wp.py list --site <ドメイン> --search "<キーワード>"` で探す。
   - 「1〜10番目の記事」のような指定は、`list` の並び（新しい順）で数える。迷ったら候補を見せて確認する。
   - 「要リライトの記事を直して」と頼まれたら、`python3 tools/wp.py queue --site <ドメイン>` で一覧を出し、古いもの（一覧の上）から順に作業する。

2. **記事を取得する**
   - `python3 tools/wp.py get --site <ドメイン> --id <記事ID> --out work/<記事ID>.html`
   - 出力されたタイトル、抜粋、文字数を確認する。
   - 出力の `memo` に要リライトのメモがあれば、そこに書かれた箇所と根拠URLを必ず直す。

3. **リライト案を作る**
   - 内部リンクを入れるときは、先に `python3 tools/wp.py links --site <ドメイン> --out work/links.json` で記事一覧を取り、内容の近い記事を選ぶ。
   - `work/<記事ID>.html` をコピーして `work/<記事ID>.rewrite.html` を作り、そこを編集する。
   - 方針（ユーザーの指示が優先）：
     - 検索意図に答える内容を冒頭に置き、結論を先に書く。
     - 古い情報（年、価格、制度など）を見つけたら直す。確かめられない数字は変えずに、報告に「要確認」として挙げる。
     - 見出し構成を整理し、重複や冗長な文を削る。
     - アフィリエイトリンク、ショートコード、SWELLのブロック（`<!-- wp:loos/... -->`）、画像ブロックは消さない。
     - ブロックのコメント（`<!-- wp:paragraph -->` と `<!-- /wp:paragraph -->` など）は必ず対で残す。
   - ユーザーが体験談や画像を渡した場合：
     - 画像は `python3 tools/wp.py upload --site <ドメイン> --file <画像パス> --alt "<説明>"` でアップロードし、返ってきたURLで画像ブロックを入れる：
       `<!-- wp:image {"id":<media_id>,"sizeSlug":"large"} -->`
       `<figure class="wp-block-image size-large"><img src="<url>" alt="<説明>" class="wp-image-<media_id>"/></figure>`
       `<!-- /wp:image -->`
     - 体験談は、記事の流れに合う見出しの下に、本人の言葉を活かして組み込む。内容を誇張しない。

4. **下書きとして保存する**
   - `python3 tools/wp.py draft --site <ドメイン> --source-id <記事ID> --content work/<記事ID>.rewrite.html`
   - タイトルも変える場合は `--title "<新しいタイトル>"` を付ける。
   - 元の記事のメモは自動で「対応中」になる。反映すると「完了」になる。

5. **報告する**
   - プレビューURL（`draft` の結果の `note` のとおりに伝える。プラグイン0.3.0以上ならログインなしで開ける）
   - `compare` があれば「変更点の比較」URLとして添える（いまの記事とリライト案の違いが色分けで見られる）
   - 主な変更点を3〜5行で
   - 要確認の点があればその一覧
   - 「OKなら『反映して』（日時を指定して予約反映もできます）、直したい点があれば教えてください」と伝える。

## 修正を頼まれたら

`work/<記事ID>.rewrite.html` を直し、古いリライト案を `wp.py discard` で破棄してから、手順4からやり直す。
