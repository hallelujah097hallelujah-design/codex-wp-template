# 記事の点検

1. `python3 tools/wp.py audit --site <ドメイン>` で全記事を点検する（数分かかることがある）。前回の結果だけ見るときは `--results` を付ける。
2. 結果を日本語で短く報告する：リンク切れ・画像の説明文なし・確認できないリンクの件数と、件数の多い記事。
   - 「確認できないリンク」は、相手のサイトが自動チェックを断っているだけのことが多い。リンク切れとは分けて伝える。
3. 直してほしいと言われたら、記事ごとに `wp-rewrite` の手順でリライト案を作る（公開記事を直接書き換えない）。
   - 画像の説明文：画像の内容と前後の文から、短く具体的な説明を付ける。
   - リンク切れ：内部リンクは `wp.py links` の一覧から正しい記事に差し替える。外部リンクは公式の新しいページを探し、見つからなければリンクを外して報告する。アフィリエイトリンクは勝手に差し替えず、ユーザーに確認する。
4. WordPressの「ツール → Codex接続 → 記事の点検」でも同じ結果が見られる。
