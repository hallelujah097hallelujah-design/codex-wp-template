# リライト案の反映

1. どのリライト案か確認する。分からなければ `python3 tools/wp.py list --site <ドメイン> --status draft --search "リライト案"` で一覧を出して確認する。
2. **反映する場合**：`python3 tools/wp.py apply --site <ドメイン> --draft-id <下書きID>`
   - タイトルを元のままにしたい場合は `--keep-title` を付ける。
   - 元の記事の本文が置き換わる。リライト前の本文は「リライト前のバックアップ」としてゴミ箱に30日間残るので、戻したいときはそこから復元できる。
3. **日時を指定された場合（予約反映）**：`python3 tools/wp.py schedule --site <ドメイン> --draft-id <下書きID> --at "YYYY-MM-DD HH:MM"`
   - 時刻はサイトの時計（`wp.py info` の `timezone`）で指定する。「明日の朝9時」などは今日の日付から計算し、実行前に「◯月◯日 9:00 に反映します」と確認する。
   - その時刻を過ぎて最初にサイトが表示されたときに反映される（アクセスが少ないと数分遅れることがある）。
   - 取り消すときは `python3 tools/wp.py unschedule --site <ドメイン> --draft-id <下書きID>`。
4. **破棄する場合**：`python3 tools/wp.py discard --site <ドメイン> --draft-id <下書きID>`
5. 結果（記事URLまたは反映予定の日時）を日本語で短く報告する。
