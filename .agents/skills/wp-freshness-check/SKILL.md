# 鮮度チェック

このスキルは記事を**書き換えない**。古い箇所を見つけてメモを残すだけにする。直す作業は `wp-rewrite` が担当する。

## 手順

1. 対象サイトのルールを読む：`rules/` 全体と `sites/<ドメイン>/`（特に `profile.md` の「情報源」）。
2. 対象記事を決める。
   - 指定がなければ、`python3 tools/wp.py list --site <ドメイン> --per-page 50` で一覧を取り、更新日（modified）が古い順に10記事程度を選ぶ。
   - 「3か月以上前」などの条件があれば、その条件で絞る。
3. 記事ごとに確認する。
   - `python3 tools/wp.py get --site <ドメイン> --id <記事ID> --out work/<記事ID>.html` で本文を読む。
   - 本文に出てくる料金、日付、キャンペーン、制度、店舗数、商品の仕様など、変わりうる情報を拾い出す。
   - `sites/<ドメイン>/profile.md` の情報源（公式サイト）を開いて照らし合わせる。
4. 結果をメモとして残す。
   - 古い・食い違う情報があった場合：
     `python3 tools/wp.py note --site <ドメイン> --id <記事ID> --status needs_rewrite --note "<どこが・何が古く・何に直すべきか>" --source <確認したURL>`
   - メモには、見出し名や該当の文、正しい情報、確認した日を具体的に書く。例：「見出し『料金プラン』の月額9,800円 → 公式では2026年10月から10,800円」
   - 問題がなかった場合：`python3 tools/wp.py note --site <ドメイン> --id <記事ID> --status ok --source <確認したURL>`
   - 確かめられなかった情報は「要確認」としてメモに書き、推測で古いと決めつけない。
5. 最後に、要リライトにした記事と理由を一覧で報告する。

すでに要リライトのメモがある記事に追記するときは `--append` を付ける。
