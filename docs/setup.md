# 初期設定の手順（試作版）

GitHubでファイルを編集する作業はありません。やることは「WordPressにプラグインを入れてボタンを押す」「表示された値をCodexに貼る」の2つだけです。

## 1. WordPressに「Codex接続」プラグインを入れる（サイトごとに1回）

1. [codex-connect.zip](../wordpress-plugin/codex-connect.zip) をダウンロードします。
2. WordPressの管理画面で「プラグイン → 新規追加 → プラグインのアップロード」から、このZIPをアップロードして有効化します。
3. 「ツール → Codex接続」を開き、「接続情報を作成」を押します。
   - Codex専用の「編集者」ユーザーとアプリケーションパスワードが自動で作られ、Codexに貼る値が表示されます。
   - Codexに登録する名前（例：`WP_SITE_PILATES_BIYORI_JP`）はドメインから自動で決まります。サイトごとに違う名前になるので、別のサイトを上書きすることはありません。
   - 表示はこの画面だけです。次の手順で貼り付けるまで画面を閉じないでください。
4. エックスサーバーの場合は、サーバーパネルの「WordPressセキュリティ設定」で、そのドメインの **「REST APIへの国外アクセス制限」をオフ** にします（Codexのクラウドは海外から接続するため）。

## 2. テンプレートを自分のGitHubにコピーする（最初に1回）

このリポジトリの「Use this template」→「Create a new repository」を押し、公開設定を **Private** にして作成します。中身を編集する必要はありません。

## 3. Codexに値を貼る（サイトごとに1回）

ChatGPT（Codex）の「Settings → Codex Cloud → Personal vault」を開き、プラグインの画面に表示された値をコピーして貼ります。

- **環境変数**：名前 `WP_SITE_<ドメイン>`、値はサイトのURL
- **ネットワークシークレット**：名前 `WP_AUTH_<ドメイン>`、値は `Basic ...` の1行、許可するドメインはサイトのドメイン

名前・値ともプラグインの画面の「コピー」ボタンでそのまま貼れます。同じ名前がすでにあるときは、新しく追加せず値を置き換えます。

## 4. Codexのクラウド環境を作る（最初に1回）

1. Codexの「クラウド環境」の設定で新しい環境を作り、手順2でコピーしたリポジトリを選びます。
2. 「インターネットアクセス」をオンにし、「指定したドメインのみ」でサイトのドメインを追加します。
3. 環境を保存して公開します。

## 5. 使ってみる

Codexでこの環境を選び、次のように頼みます。

- 「登録しているサイトの一覧を見せて」
- 「ピラティスのサイトの『ふるさと納税 おすすめ』の記事をリライトして」
- 「この体験談と写真を、example.com の〇〇の記事に入れて」

リライト案は「【リライト案 #記事ID】」という下書きで保存され、プレビューURLが返ってきます。このURLはログインしなくても開けます（7日間有効、反映すると使えなくなります）。確認して問題なければ「反映して」と伝えます。
反映すると、リライト前の本文は「【リライト前のバックアップ】」としてゴミ箱に30日間残ります。

## 6. プラグインのそのほかの機能

- **変更点の比較**：リライト案と一緒に「変更点の比較」URLが届きます。いまの記事とリライト案の違いが色分けで見られます（記事一覧の「変更点を比べる」からも開けます）。
- **予約反映**：「明日の朝9時に反映して」のように日時を指定できます。記事一覧のリライト案に「予約反映 日時」と表示されます。
- **ダッシュボードの「Codexの今週の作業」**：今週反映した記事、確認待ちのリライト案、要リライトの件数がひと目で分かります。
- **作業履歴**（ツール → Codex接続）：Codexが行った変更が日時つきで残ります。
- **Codexからの操作**（同）：「通常／読み取りのみ／一時停止」を切り替えられます。パスワードはそのままで、Codexだけを止められます。
- **記事の点検**（同）：全記事の画像の説明文の抜けとリンク切れを調べます。Codexに「記事を点検して」と頼んでも同じです。
- **サイト情報**（同）：テーマ・プラグイン・カテゴリーなどの一覧。Codexも自分で読み取ります。
- **記事一覧の「Codex」列とメモ欄**：要リライトなどの状態を記事ごとに確認・変更できます。
- **自動更新**：プラグインの新しい版が出ると、ほかのプラグインと同じように「更新があります」と表示されます。プラグイン一覧の「自動更新を有効化」を押しておくと、自動で最新になります。
